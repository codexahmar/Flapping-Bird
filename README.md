# Flapping Bird

A classic Flappy Bird clone built with vanilla HTML, CSS, and JavaScript.

## How to Play

1. Open `index.html` in any web browser
2. Press **Spacebar** or **Click** to flap the bird
3. Navigate through the pipes without hitting them
4. Score points for each pipe successfully passed
5. Press **Enter** to restart after game over

## Features

- Smooth physics-based movement
- Collision detection
- Score tracking
- Game over and restart functionality
- Clean visual design

## Files

- `index.html` - Game structure
- `styles.css` - Visual styling
- `game.js` - Game logic
